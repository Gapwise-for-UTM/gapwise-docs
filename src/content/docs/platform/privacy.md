---
title: Privacy
description: Privacy boundaries for the Gapwise developer platform.
---

The public Gapwise campus API is designed to work without student timetables, student records, or private account access.

Public developer resources must not expose private timetable data, friend data, precise location history, private preferences, crowd-reporter identity, credentials, or internal moderation state.

Gapwise's raw ACORN `.ics` import is handled locally by the student application and is not part of the public developer API.
