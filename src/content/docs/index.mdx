## Choose your integration

Gapwise has **two intentionally separate developer surfaces**. Pick the one that matches the data and trust boundary your product actually needs.

<CardGrid>
  <Card title="Public API & SDKs" icon="seti:json">
    Use the unauthenticated public platform for canonical UTM buildings and places, deterministic routing, and route-aware gap planning. It never exposes a student's timetable, account, friends, private sync state, or precise live location.

    **[Start with the public API →](/quickstart/#public-api-quickstart)**
  </Card>
  <Card title="Gapwise AI & MCP" icon="rocket">
    Connect a compatible remote MCP client to explicitly delegated Gapwise context and bounded actions. Private access is OAuth-protected, permissioned, minimized, revision-aware, and revocable.

    **[Explore AI & MCP →](/ai/)** · **[Connect a client →](/ai/connect/)**
  </Card>

## Why build on Gapwise

## Production developer surfaces

### Public campus platform

The canonical public API exposes versioned UTM buildings and places, deterministic building-to-building routing, and route-aware assessment of an explicitly supplied free interval.

- API base: `https://api.gapwise.ca/v1`
- OpenAPI 3.1: `https://api.gapwise.ca/openapi.json`
- Public developer hub: `https://gapwise.ca/developers`
- Source: `https://github.com/andrewmuratov/gapwise`
- JavaScript / TypeScript: `npm install @gapwise/sdk@0.1.0`
- Python: `python -m pip install gapwise==0.1.0`

Successful responses use `{ data, meta }`; errors use a nested structured error envelope with a request ID. Both official SDKs target the same v1 contract. `@gapwise/sdk@0.1.0` is published on npm with provenance, and `gapwise==0.1.0` is published on PyPI through Trusted Publishing and has been independently clean-installed against the production API.

### Permissioned Gapwise AI / MCP

Gapwise AI is a separate provider-neutral remote MCP service. The client supplies the model and reasoning layer; Gapwise supplies permissioned tools and deterministic facts.

- MCP resource: `https://ai.gapwise.ca/api/mcp`
- OAuth protected-resource metadata: `https://ai.gapwise.ca/.well-known/oauth-protected-resource`
- AI service: `https://ai.gapwise.ca`
- Source: `https://github.com/andrewmuratov/gapwise-ai`

The live handler currently exposes **13 permissioned tools** for delegated reads, planning, status, and bounded queued writes. Academic meetings remain read-only. Four stateless public-campus MCP tool definitions exist in source but are intentionally **not registered** in the live handler; the public campus API remains their canonical public path.

Broad named-client compatibility is still a release gate. These docs do not claim ChatGPT, Claude, or another named client as fully verified until the production OAuth/read/write/revoke matrices are complete. See [Client compatibility](/ai/compatibility/).
