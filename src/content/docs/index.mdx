## Current public surface

Gapwise currently exposes canonical UTM building and place data, deterministic building-to-building routing, and route-aware gap assessment. The API is evolving toward a stable versioned `v1` surface at `api.gapwise.ca`.

> Gapwise is an independent project and is not an official University of Toronto service unless explicitly stated otherwise.
