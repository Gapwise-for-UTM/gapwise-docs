## Production developer surface

Gapwise exposes a stable `v1` surface for canonical UTM buildings and places, deterministic building-to-building routing, and route-aware assessment of an explicitly supplied free interval. Successful responses use `{ data, meta }`; errors use a nested structured error envelope with a request ID.

Official JavaScript/TypeScript and Python SDK source is release-ready in the Gapwise repository and uses the same v1 contract. Registry publication is handled separately from the API deployment, so raw HTTPS remains the universal integration path.

- API base: `https://api.gapwise.ca/v1`
- OpenAPI: `https://api.gapwise.ca/openapi.json`
- Source: `https://github.com/andrewmuratov/gapwise`

> Gapwise is an independent project and is not an official University of Toronto service unless explicitly stated otherwise.
